## A1 — C6 as declared (a correction of the runner, not of the rule)

The declaration's C6 compares the first metered day with "the unit's first
appearance in **any** register copy". Version 1's runner took a project's
first sighting **within its regime**, with a gap of 0 days at a regime's
first copy (19/05/2026 for the later format), so a project printed for
years in the older format read as new on 19/05/2026. From this amendment,
a project's first appearance is its earliest kept copy across both
regimes (014's project group, the same key in each). The gap is the days
since the kept copy before it in the combined sequence, which is 301 days
at 19/05/2026.

## A2 — the walk's effective floor is the source's served start

`datasets/B1610/stream` serves no record before 2019-01-29 for any unit.
Amendment 3's floor of 2015-01-01 was never reached. **The effective floor
is the first window in which the walk found records for any project
(2019-01-29 to 2019-02-04).** A project whose earliest record falls in
that window has output the walk cannot date: it is labelled
`metered-before-the-walk`, is not measured, and is counted in every
figure, with the floor stated. This changes what version 1 can say:
realised delays exist only for plants whose output began after the source's
served start.

## A3 — plants measured twice

A project whose admitted unit or set is also admitted for an earlier
project of the population, and whose first `Built` copy is later, is a
**second sighting** (the same plant printed again under a respelt
customer). It is labelled `second-sighting`, listed beside its first
sighting, and not measured; the first sighting is kept. In version 1 these
are Goose House Lane, Moorfield Drive and Rake Lane (pre-screen #76 to #78,
against #62 to #64). The pairs asked for with the admissions are reported
as such.

## A4 — embedded plant metering before the register prints it

C6 assumed a metering day before a project's first appearance is an
identity error. For **embedded** plant (J3 reads `embedded-or-distribution`
from the copy before), the assumption fails: embedded plant can take TEC
after it is already generating, so the register can print it later than its
first output. Such a project, if it fails A1's C6, is labelled
`metered-before-register`. It is listed, excluded from the delay figures,
and **not counted as a C6 failure for F4**. C6 keeps its force for
directly connected projects and for those J3 cannot determine.
